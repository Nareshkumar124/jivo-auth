{% comment %} A built board: the factory's CustomBoardView.tsx, CardFace.tsx and CardViz.tsx as one Django template. `board` is the service's payload (`board.board` is the board row, `board.cards` the placed cards), `meta` its meta and `slide` the registry entry. Every tile is `.ops-grp`, the same four-row tile the Plant and Logistics boards are built from, wearing its hue through an `ops-b-*` class, so a card here and the same card on the factory's wall draw the same bar the same way. THE HEADING IS THE TOPBAR. The factory draws the board's name as a header row above the grid; here that row is the `.ops-topbar` every slide in the rotation carries (live pill, name, clock), so the grid keeps the height the fixed boards' stacks have. `show_heading` decides whether the board's own name and description sit in it; the pill and the clock stay, because a wall that has lost its clock cannot be told from a frozen tab. FOUR REASONS A CARD CAN BE BLANK, KEPT APART. A card whose payload is null renders an `.ops-unread` tile with the reason from `meta.reasons`, never a zero. Retired and misplaced cards have no tile to say it on, so they are said once in the meta strip. Nothing is withheld on this wall. All geometry (bar widths, column heights, figures) is precomputed by the service in `built_cards/viz.present()`; this template only prints it. {% endcomment %}{% load boards %} {% with b=board.board %}
